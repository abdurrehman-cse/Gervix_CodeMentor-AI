`frontend/scripts/version-smoke.cjs` submits three significant real code versions. It checks v1 diagnostics, hints and failing execution; v2 rewriting, obsolete fix-preview cancellation, outdated-test disabling, and unchanged-submission deduplication; then holds an older v2 response while v3 finishes and confirms it cannot overwrite v3. Fresh v3 tests pass against v3 code, complexity is provenance-tagged, historical v1 tests still fail without changing v3, v2/v3 line diffs show actual additions/removals, and history/reviews survive refresh. Cancelling restore leaves drafts unchanged; confirmed restore preserves unsaved drafts in a backup version, creates a restore version and loads its new working state. A simulated storage failure cannot create a phantom version or discard working source.

The original selection failure was reproduced before changes: displaying the conditional selection toolbar moved Monaco down and reduced its height by 37 pixels during mouse drag. Monaco's mouse handler stops its move monitor when editor height changes, prematurely ending the selection. The toolbar now reserves a constant height even with no selection, removing the triggering layout change. Stable editor options and change callbacks, native model-owned edits, and model-specific view states avoid unnecessary resets. Actions read the live Monaco range rather than a stale React snapshot.

The live external AI service requires server credentials and has not been tested against a real provider in this environment. Adapter tests use explicit mocked provider responses, including malformed JSON and failed requests. No external AI results are simulated in the product. Without a key, the UI labels its limited local analysis and mentoring.

The runner executes standalone files in browser isolation with time and output limits. Module execution and operating-system memory limits are outside this MVP. Compiler diagnostics and mentoring can inspect actual virtual project imports. Static complexity estimates state assumptions and are not benchmarks; passing generated tests is not a correctness proof.
